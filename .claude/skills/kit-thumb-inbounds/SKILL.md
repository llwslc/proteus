# kit-thumb-inbounds

滑块的旋钮默认以值点为中心，于是在两端各悬出半个自身宽度——落在会裁切的容器里就被削掉，落在别处则压出底条之外。判定归控件：**底条（外框）保持满宽，填充条与条头在内缩带里走，两端旋钮的自身边缘与底条边缘齐平而不越出。**

落地写法是给底条加透明横向边框（`border-inline: 半个条头宽 solid transparent` + `box-sizing: border-box`）：绝对定位子元素的包含块是 padding 盒，填充条与条头因此自动落进内缩带，而背景默认画到 border 盒，底条外观不变、不需要任何 JS 或值分数变量。

底条的可见框若画在伪元素上（`::after { inset: 0 }`），它同样按 padding 盒解析、会跟着内缩——补一条后置规则把它拉回 border 盒（`inset-inline: calc(-1 * 半个条头宽)`）。插在原 `inset` 声明之前会被覆盖，必须后置。

## Run

```
node .claude/skills/kit-thumb-inbounds/check.cjs [port] [kit]
```

逐套把滑块真拖到两端（每次拖前重新定位条头，否则按旧坐标按下会抓空），量旋钮包围盒相对底条的越界量；同时查底条元素盒是否仍与控件同宽、其伪元素可见框是否被内缩。任一越界超过 0.5px 即 FAIL。

内缩量取半个条头宽；条头带倾角时渲染盒比标称宽（riot 的 −6° 让 26px 撑到 29.4px），取能覆盖渲染盒的间距档。
